### Vector
Arreglo dinamico gracias a que C++ realiza las operaciones de realloc, malloc, calloc automaticamente.
Metodos:
    vec.size() = num de elementos del vector
    vec.push_back() = agrega el elemento al final del vector
    vec[<indice>] = intenta acceder al i-esimo indice
    vec.empty() = devuelve booleano, determina si esta vacio
